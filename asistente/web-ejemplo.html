La Tasca del Ejemplo

Así queda el asistente en la web de un restaurante (abajo a la derecha).

Esta es una web cualquiera. Para poner el asistente solo hace falta pegar una línea antes de </body>:

<script src="https://juliogomhoc-png.github.io/demos-ia/asistente/asistente.js" data-config="https://juliogomhoc-png.github.io/demos-ia/asistente/negocios/ejemplo.json" defer></script>

Funciona en WordPress, Wix, Squarespace o una web hecha a mano. Si el restaurante no tiene web, se usa la página completa (pagina.html?n=ejemplo) desde un QR en la mesa, la ficha de Google o la bio de Instagram.
